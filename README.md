# SafeHer 🛡️

SafeHer is a women-safety web application designed to provide quick access to emergency assistance, live location sharing, SOS alerts, safe routes, incident reporting, and nearby emergency services.

## 🚀 Features

* 🔴 One-tap SOS alerts
* 👥 Emergency contacts management
* 📍 Live location sharing
* 🗺️ Safe route & map support
* ⚠️ Incident reporting
* 📊 Location-based risk score
* 🚔 Nearby police stations
* 🏥 Nearby hospitals
* 🔔 Real-time Socket.IO alerts
* 👨‍💼 Admin dashboard
* 🔐 Secure authentication

## 🛠️ Tech Stack

**Frontend:** React, Vite, Tailwind CSS
**Backend:** Node.js, Express.js
**Database:** MongoDB
**Real-time:** Socket.IO
**Maps:** Leaflet / Map services
**Authentication:** JWT

## 📂 Project Structure

```text
SafeHer/
├── frontend/
└── backend/
```

## ⚙️ Setup

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```

Create `.env` files according to the required backend and frontend environment variables.

## 🎯 Goal

To build a reliable, accessible, and user-friendly digital safety platform that helps users respond quickly during emergency situations.
